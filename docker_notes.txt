1. INTRODUCTION TO DOCKER
==============================================================

DEFINITION
Docker is an open-source platform that enables developers to build,
package, distribute, and run applications inside isolated
environments called containers.

SIMPLE EXPLANATION
Docker ek platform hai jo application aur uski dependencies ko ek
container mein package karta hai.

EXAMPLE
Maan lo tumne Python mein ek Machine Learning project banaya hai.
Tumhare project ko chahiye:
  - Python 3.10
  - NumPy
  - Pandas
  - Scikit-learn
  - TensorFlow

Ab agar tum apna project kisi doosre computer par run karte ho, toh
dependency issues aa sakte hain. Docker is problem ko solve karne
mein help karta hai.

REAL-LIFE EXAMPLE
Tumhare laptop par application successfully run ho rahi hai.
Lekin AWS server par error aa raha hai.
Reason:
  - Python version mismatch.
  - Library version mismatch.
  - Missing dependencies.

Docker application ka environment package kar deta hai, jisse
deployment consistent hota hai.

IMPORTANT TERMS
  Docker        : Containerization platform.
  Container     : Isolated application environment.
  Image         : Container create karne ka template.
  Dockerfile    : Image banane ki instruction file.
  Docker Engine : Docker ka core execution system.


==============================================================
2. PROBLEMS BEFORE DOCKER
==============================================================

Docker se pehle developers ko kai problems face karni padti thi.

COMMON PROBLEMS
1. Dependency Issues
   Different systems mein different library versions.
2. Environment Mismatch
   Developer ke laptop aur production server ka environment
   different.
3. Deployment Problems
   Application ko manually configure karna padta tha.
4. Resource Consumption
   Traditional Virtual Machines ka resource overhead zyada hota
   tha.
5. Portability
   Application ko different environments mein consistently run
   karna difficult ho sakta tha.

SOLUTION
Docker application ko dependencies aur configuration ke saath
containerize karta hai.


==============================================================
3. WHAT IS CONTAINERIZATION?
==============================================================

DEFINITION
Containerization is a technology that packages an application along
with its dependencies into an isolated, portable, and lightweight
unit called a container.

EXPLANATION
Containerization ka matlab application ko ek isolated environment
mein run karna.

EXAMPLE
Tumhare laptop par teen applications hain:
  - Python ML Application
  - Node.js Application
  - MySQL Database

In sabke dependencies alag ho sakte hain. Docker har application ko
separate container mein run kar sakta hai. Isse dependency conflicts
kam hote hain.

BENEFITS
  - Portability
  - Isolation
  - Faster deployment
  - Resource efficiency
  - Scalability

4. DOCKER ARCHITECTURE
==============================================================

Docker Client-Server Architecture follow karta hai.

Main components:
  - Docker Client
  - Docker Daemon
  - Docker Host
  - Docker Registry

ARCHITECTURE FLOW

       Docker Client
             |
             |
          REST API
             |
             v
       Docker Daemon
             |
       +-----+------+
       |            |
       v            v
    Images      Containers
       |
       |
       v
  Docker Registry

1. DOCKER CLIENT
Definition: Docker Client is the interface through which users
interact with Docker.

Example:
    docker run nginx

Jab tum ye command execute karte ho, Docker Client request bhejta
hai.

2. DOCKER DAEMON
Definition: Docker Daemon is a background service responsible for
managing Docker objects.

Iska kaam:
  - Images manage karna.
  - Containers create karna.
  - Networks manage karna.
  - Volumes manage karna.

Docker Daemon ko generally "dockerd" kehte hain.

3. DOCKER HOST
Docker Host woh machine hai jahan Docker Engine aur containers run
hote hain.
Example:
  - Your Laptop
  - AWS EC2 Server
  - Linux Server

4. DOCKER REGISTRY
Definition: Docker Registry is a storage system used to store and
distribute Docker images.
Example: Docker Hub.

5. DOCKER COMPONENTS
==============================================================

A. DOCKER ENGINE
Docker Engine ek core technology hai jo Docker containers ko build
aur run karne ke liye responsible hoti hai.

B. DOCKER IMAGE
Definition: A Docker Image is a read-only template used to create
Docker containers.
Simple explanation: Image ek blueprint hai.
Example:
    docker pull python:3.10
Ye Python 3.10 image download karta hai.

C. DOCKER CONTAINER
Definition: A Docker Container is a runnable instance of a Docker
image.
Simple explanation: Image se container create hota hai.
Example:
    docker run python:3.10

D. DOCKERFILE
Definition: A Dockerfile is a text file containing instructions to
build a Docker image.
Example:
    FROM python:3.10
    WORKDIR /app
    COPY . .
    CMD ["python", "app.py"]

E. DOCKER COMPOSE
Docker Compose ek tool hai jiska use multiple containers ko ek saath
define aur manage karne ke liye hota hai.
Example: Ek application mein Frontend, Backend, Database - teeno ko
Docker Compose se manage kar sakte ho.

6. DOCKER vs VIRTUAL MACHINE
==============================================================

Dono technologies virtualization aur isolation provide karti hain,
lekin approach different hai.

Feature          | Docker Container          | Virtual Machine
-----------------+---------------------------+--------------------------
Architecture     | Containerization          | Hardware virtualization
OS               | Host kernel share karta   | Guest OS hota hai
                 | hai                       |
Size             | Generally small           | Generally large
Startup          | Fast                      | Comparatively slow
Resource Usage   | Generally less            | Generally more
Isolation        | Process-level             | Hardware-level
                 |                           | virtualization
Performance      | Low overhead              | More overhead

VIRTUAL MACHINE ARCHITECTURE        DOCKER ARCHITECTURE
   Applications                        Applications
   Libraries                           Libraries
   Guest OS                            Docker Container
   Hypervisor                          Docker Engine
   Hardware                            Host OS
                                       Hardware

INTERVIEW POINT: Containers share the host operating system kernel,
whereas virtual machines run their own guest operating systems.

10. DOCKERFILE
==============================================================

Ye Docker ka bahut important topic hai.

DEFINITION
A Dockerfile is a text document that contains instructions to build
a Docker image.

EXAMPLE: PYTHON APPLICATION

Project structure:
    my-project/
    |
    |-- app.py
    |-- requirements.txt
    |-- Dockerfile

app.py
    print("Hello from Docker!")

requirements.txt
    numpy
    pandas

Dockerfile
    FROM python:3.10

    WORKDIR /app

    COPY requirements.txt .

    RUN pip install -r requirements.txt

    COPY . .

    CMD ["python", "app.py"]

DOCKERFILE INSTRUCTIONS
Instruction | Meaning
------------+------------------------------------------------
FROM        | Base image define karta hai
WORKDIR     | Working directory set karta hai
COPY        | Files copy karta hai
ADD         | Files copy/extract kar sakta hai
RUN         | Build time par command execute karta hai
CMD         | Default startup command define karta hai
ENTRYPOINT  | Main executable define karta hai
ENV         | Environment variables set karta hai
EXPOSE      | Intended container port document karta hai
ARG         | Build-time variable define karta hai
USER        | User set karta hai
VOLUME      | Mount point declare karta hai

RUN vs CMD
  RUN : Image build ke time execute hota hai.
        Image layer create karta hai.
  CMD : Container start hone par execute hota hai.
        Default startup command define karta hai.

CMD vs ENTRYPOINT
CMD default command ya arguments define karta hai.
ENTRYPOINT container ka primary executable define karta hai.
Dono saath bhi use ho sakte hain.

Example:
    ENTRYPOINT ["python"]
    CMD ["app.py"]

12. DOCKER VOLUMES
==============================================================

DEFINITION
Docker Volumes are used to persist data generated and used by Docker
containers.

PROBLEM
Normally container remove karne par uske writable filesystem ka data
bhi remove ho jata hai.

Example: Tumhare paas MySQL container hai. Usmein database data save
hai. Agar container remove kar diya, toh bina persistent storage ke
data lose ho sakta hai.

SOLUTION: VOLUMES
Volume container ke lifecycle se independent data store karta hai.

VOLUME COMMANDS
Create Volume    : docker volume create mydata
List Volumes     : docker volume ls
Inspect Volume   : docker volume inspect mydata
Remove Volume    : docker volume rm mydata

VOLUME ATTACH KARNA
    docker run -d \
      --name mycontainer \
      -v mydata:/app/data \
      nginx

Yahan:
  mydata    = Volume name.
  /app/data = Container ke andar mount location.

TYPES OF STORAGE
Type        | Purpose
------------+-----------------------------------------------
Volume      | Persistent Docker-managed storage
Bind Mount  | Host machine ki specific directory mount karna
tmpfs       | Memory-based temporary storage

13. DOCKER NETWORKING
==============================================================

DEFINITION
Docker Networking allows containers to communicate with each other
and external networks.

Simple explanation: Maan lo tumhare paas Frontend container, Backend
container, Database container hai. In containers ko communicate
karne ke liye networking use hoti hai.

DOCKER NETWORK TYPES
1. Bridge Network
   Default local container networking ka common mode.
2. Host Network
   Container host ke networking namespace ko share karta hai. Ye
   mainly Linux par relevant hai.
3. None Network
   Container ko normal external network connectivity nahi milti.
4. Overlay Network
   Multiple Docker hosts ke across container networking provide
   karta hai, commonly Swarm mein.

NETWORK COMMANDS
    docker network ls
    docker network create mynetwork
    docker network inspect mynetwork
    docker network rm mynetwork

Container ko network mein connect:
    docker network connect mynetwork mycontainer

14. DOCKER COMPOSE
==============================================================

DEFINITION
Docker Compose is a tool used to define and manage multi-container
Docker applications using a YAML configuration file.

EXAMPLE
Suppose tum ek AI chatbot bana rahe ho. Tumhare project mein:
  - FastAPI Backend
  - PostgreSQL Database
  - Redis Cache

Teeno ko separately manage karna difficult ho sakta hai. Docker
Compose se teeno services define kar sakte ho.

docker-compose.yml
    services:

      backend:
        build: .
        ports:
          - "8000:8000"
        depends_on:
          - database

      database:
        image: postgres:16
        environment:
          POSTGRES_USER: admin
          POSTGRES_PASSWORD: password
          POSTGRES_DB: mydb
        volumes:
          - postgres_data:/var/lib/postgresql/data

    volumes:
      postgres_data:

IMPORTANT COMMANDS
Start Services        : docker compose up
Run in Background     : docker compose up -d
Stop Services         : docker compose down
Build Services        : docker compose build
View Containers       : docker compose ps
View Logs             : docker compose logs
Follow Logs           : docker compose logs -f

NOTE: docker compose down -v named volumes bhi remove kar sakta hai.
Isse persistent database data delete ho sakta hai.

16. DOCKER PORT MAPPING
==============================================================

DEFINITION
Port Mapping allows external traffic to access a service running
inside a Docker container.

Example:
    docker run -d -p 8000:8000 myapp

Iska meaning:
    Host Port : Container Port
       8000   :      8000

Agar tum browser mein open karte ho:
    http://localhost:8000
Toh request container ke application tak pahunch sakti hai.

IMPORTANT: EXPOSE aur -p same nahi hain.

  -p     : Actual host-to-container port mapping create karta hai.

19. DOCKER MULTI-STAGE BUILDS
==============================================================

DEFINITION
Multi-stage builds allow developers to use multiple FROM
instructions in a Dockerfile to create smaller and more efficient
final images.

PROBLEM
Build process mein kai unnecessary dependencies install hoti hain.
Lekin production application ko un sabki zaroorat nahi hoti.
Multi-stage builds unnecessary build tools ko final image se exclude
karne mein help karte hain.

EXAMPLE
    FROM python:3.10 AS builder

    WORKDIR /app

    COPY requirements.txt .

    RUN pip install --prefix=/install -r requirements.txt


    FROM python:3.10-slim

    WORKDIR /app

    COPY --from=builder /install /usr/local

    COPY . .

    CMD ["python", "app.py"]

Ismein:
  - First stage dependencies install karta hai.
  - Second stage final runtime image prepare karta hai.
  - First stage ke unnecessary build tools final image mein nahi
    aate.

20. DOCKER SECURITY
==============================================================

Docker mein security important hai, especially jab tum production
applications deploy karte ho.

IMPORTANT SECURITY PRACTICES
  - Trusted base images use karo.
  - Container ko root user ke roop mein run karne se bacho.
  - API keys hardcode mat karo.
  - Images regularly update karo.
  - Unnecessary packages install mat karo.
  - Containers ko minimum required permissions do.
  - Image vulnerabilities scan karo.

NON-ROOT USER EXAMPLE
    FROM python:3.10-slim

    WORKDIR /app

    RUN useradd -m appuser

    COPY . .

    USER appuser

    CMD ["python", "app.py"]

22. DOCKER WITH FASTAPI
==============================================================

AI/ML Engineers ke liye FastAPI + Docker combination bahut useful
hai.

Example: Tumhare paas ML model hai aur tum usse API ke through serve
karna chahte ho.

PROJECT STRUCTURE
    ml-api/
    |
    |-- main.py
    |-- requirements.txt
    |-- Dockerfile

main.py
    from fastapi import FastAPI

    app = FastAPI()

    @app.get("/")
    def home():
        return {
            "message": "ML API Running"
        }

requirements.txt
    fastapi
    uvicorn

Dockerfile
    FROM python:3.10-slim

    WORKDIR /app

    COPY requirements.txt .

    RUN pip install --no-cache-dir -r requirements.txt

    COPY . .

    EXPOSE 8000

    CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

Build:
    docker build -t ml-api .

Run:
    docker run -d -p 8000:8000 ml-api

Browser mein open karo:
    http://localhost:8000

API documentation:
    http://localhost:8000/docs

25. DOCKER vs KUBERNETES
==============================================================

Ye dono different technologies hain.

Docker                               | Kubernetes
-------------------------------------+--------------------------------
Container platform                   | Container orchestration platform
Containers build/run karta hai       | Containers manage karta hai
Single host par useful               | Multiple machines par scale
                                     | kar sakta hai
Docker Compose multi-container apps  | Kubernetes large distributed
manage karta hai                     | workloads manage karta hai
Container lifecycle manage karta hai | Scheduling, scaling, recovery
                                     | manage karta hai

SIMPLE EXAMPLE
  Docker     : Ek container create aur run karna.
  Kubernetes : Hundreds of containers ko multiple servers par manage
               karna.

NOTE: Kubernetes ko sirf Docker ke saath hi use karna zaroori nahi
hai. Ye multiple container runtimes support karta hai.

27. DOCKER INTERVIEW QUESTIONS
==============================================================

Ye questions fresher aur junior AI/ML or backend roles ke
interviews mein useful hain.

BASIC QUESTIONS

Q1. What is Docker?
Docker is an open-source platform used to build, package, and run
applications inside containers.

Q2. What is a Docker Image?
A Docker Image is a read-only template used to create containers.

Q3. What is a Docker Container?
A Docker Container is a runnable instance of a Docker image.

Q4. What is Dockerfile?
Dockerfile is a text file containing instructions to build a Docker
image.

Q5. What is Docker Hub?
Docker Hub is a registry used to store and distribute Docker images.

Q6. What is Docker Compose?
Docker Compose is a tool used to manage multi-container applications
using YAML configuration.

INTERMEDIATE QUESTIONS

Q7. Difference between Image and Container?
Image is a template, whereas container is a runnable instance of
that image.

Q8. Difference between RUN and CMD?
RUN executes commands during image building, whereas CMD defines the
default command when a container starts.

Q9. What is Docker Volume?
Docker Volume provides persistent storage for container data.

Q10. What is Port Mapping?
Port mapping connects a host machine port to a container port.

Q11. What is Docker Networking?
Docker Networking enables communication between containers and
external networks.

Q12. What is Multi-stage Build?
It uses multiple build stages to produce optimized final images.

ADVANCED QUESTIONS

Q13. What is Docker Daemon?
Docker Daemon is a background service that manages Docker images,
containers, networks, and volumes.

Q14. What is Containerization?
Containerization is a method of packaging applications with
dependencies into isolated containers.

Q15. What is the difference between Docker and Kubernetes?
Docker provides containerization tools, whereas Kubernetes
orchestrates containers across a cluster.
